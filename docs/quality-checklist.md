### Итоговый чек-лист для команды

**1. Данные разделены правильно?**
- Train: 8 000 заявок (обучение + fit TF-IDF)
- Validation: 2 000 заявок (настройка гиперпараметров)
- Test: 2 000 заявок (финальная оценка, не трогать до конца!)
**2. Нет data leakage?**
- TF-IDF: .fit() только на train
- TF-IDF: .transform() на validation/test уже обученным векторизатором
**3. Метрики выбраны из цены ошибки?**
- Macro F1 ≥ 0.72 (все классы важны)
- Recall critical ≥ 0.80 (критические нельзя пропускать)
- Confusion matrix построена (видим, какие классы путаем)
**4. Артефакты проверяемы?**
- Любой участник может открыть документ и однозначно сказать: выполнено или нет
- Каждый критерий имеет артефакт (скриншот, отчёт, таблица, лог)
**5. Объяснена ли проблема для каждого технического решения?**
- Не просто «используем логистическую регрессию», а «используем логистическую регрессию для быстрой базовой классификации, проверяем через Macro F1»
